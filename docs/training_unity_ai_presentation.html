🔥 KHỐI 2 · KHÁC BIỆT

Task: Thêm hệ thống Loot Drop khi Enemy chết

So sánh trực quan hai phong cách giao việc đầu vào

❌ PROMPT YẾU (Dev thường hỏi)

"thêm loot drop khi enemy chết"

  • AI tự đoán Loot gồm item hay gold và tự spawn bừa bãi
  • Nó tự động sửa lung tung vào Enemy.cs mà bạn không hề biết
  • Nó tự ý kết nối bừa bãi sang InventoryManager hay Database
  • Code "chạy được" nhưng phá hỏng cấu trúc Clean Code của team

    • ✅ BRIEF TỐT (Phong cách Tech Lead)

    [VAI TRÒ] Unity gameplay engineer làm việc trong codebase này.

    [CONTEXT] Unity 6, đã có ScriptableObject ItemData cho item. Enemy.cs đã có event OnDeath. LootTable là field [SerializeField] trên Enemy prefab.

    [TASK] Khi OnDeath fire, spawn item theo LootTable tại vị trí enemy. Mỗi entry trong LootTable có dropRate (0-1). KHÔNG sửa InventoryManager.

    [OUTPUT] Liệt kê file sẽ tạo/sửa; Code sạch có XML comment; Đợi tôi duyệt.

    🚧 KHỐI 3 · SCOPE CONTROL

    Plan trước, Code sau

    Kỹ thuật quan trọng nhất để tránh AI phá hỏng dự án

    Đừng cho phép AI tự ý gõ code ngay lập tức. Hãy dựng một ranh giới chặt chẽ bắt nó phải lên kế hoạch trước.

    // Bắt AI dừng lại suy nghĩ và cam kết scope trước khi viết code
    Yêu cầu:
    "Trước khi viết bất kỳ dòng code nào, hãy trình bày kế hoạch chi tiết:
    1. Liệt kê chính xác các file sẽ tạo mới hoặc sửa đổi.
    2. Mô tả ngắn gọn thay đổi cốt lõi trong từng file đó.
    3. Đánh giá rủi ro và các module có khả năng bị ảnh hưởng.
    Đợi tôi approve kế hoạch này trước khi bạn bắt đầu code."
    Thần chú scope: Cấu hình câu lệnh này vào Cursor Rules hoặc paste trực tiếp ở lượt chat đầu tiên.

    🔍 KHỐI 4 · CODE REVIEW

    5 dấu hiệu code AI "trông đúng mà sai"

    Đọc code AI nghiêm ngặt hơn cả code đồng nghiệp

    Bởi vì AI viết code trông cực kỳ sạch sẽ và hoàn hảo, nhưng các lỗi logic chí mạng thường bị ẩn giấu rất sâu dưới các dòng chú thích đẹp đẽ.

    1
    Tên hàm đúng nhưng logic thiếu
    Hàm ghi CalculateDamage nhưng bên trong quên nhân với giáp (Armor) của mục tiêu.
    2
    Ảo giác API (API Hallucination)
    Nó tự chế ra các hàm UnityEngine.X.Y() không hề tồn tại trong phiên bản Unity hiện tại.
    3
    Ngược dấu logic so sánh
    Rất hay nhầm lẫn toán tử: if (hp > 0) chết thay vì if (hp <= 0).
