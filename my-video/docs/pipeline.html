Giai đoạn 1 Khởi tạo & Thiết lập (Scaffolding)

Thiết lập môi trường làm việc chuẩn cho dự án. Hyperframes tự động tạo cấu trúc và cung cấp các tệp chỉ dẫn dành riêng cho AI Agents để lập trình dễ dàng nhất.

npx hyperframes init <ten-du-an>
  • index.html: Điểm bắt đầu chứa khung HTML của video.
  • hyperframes.json: Cấu hình độ phân giải, tốc độ khung hình (fps) và danh sách compositions.
  • AGENTS.md & CLAUDE.md: Hướng dẫn tối ưu hóa tác vụ cho các trợ lý AI.
Giai đoạn 2 Xử lý Tài nguyên Đa phương tiện (Media Preprocessing)

Hyperframes hỗ trợ các tác vụ AI mạnh mẽ chạy trực tiếp trên thiết bị (Local AI) mà không cần cài đặt phức tạp hay đăng ký API trực tuyến bên ngoài.

// 1. Chuyển văn bản thành giọng thuyết minh (Mô hình Kokoro-82M)\nnpx hyperframes tts "Chào mừng tới Barcelona!" -v af_heart -o assets/v1.wav\n\n// 2. Tạo phụ đề khớp mốc thời gian từ file âm thanh (Mô hình Whisper)\nnpx hyperframes transcribe assets/v1.wav -o assets/transcript.json\n\n// 3. Tách nền ảnh/video tạo overlay trong suốt (Mô hình u2net)\nnpx hyperframes remove-background assets/avatar.png
Giai đoạn 3 Thiết kế Bố cục & Hiệu ứng (Composition & Styling)

Bạn tự do thiết kế bố cục phân cảnh bằng mã HTML và trang trí thẩm mỹ cao bằng mã CSS tiêu chuẩn (hỗ trợ sẵn Tailwind CSS v4).

  • Thuộc tính định thời gian: Quản lý xuất hiện bằng data-start, data-duration, data-track-index trực tiếp trên thẻ HTML.
  • Chuyển động (Animations): Sử dụng GSAP Timeline để đồng bộ chuyển động hoàn hảo với trục thời gian của Hyperframes.
  • Hỗ trợ phong phú: Cho phép tích hợp Lottie, WebGL (Three.js), CSS Keyframes để làm hiệu ứng phong phú.
Giai đoạn 4 Xem trước thời gian thực (Live Preview & Studio)

Không cần đợi render! Chạy máy chủ xem trước để kiểm tra ngay lập tức các thay đổi thiết kế trên trình duyệt web.

npm run dev // (Hoặc npx hyperframes preview)
  • Hot Reload: Tự động làm mới khung hình bất cứ khi nào lưu code.
  • Ask Agent: Khung chat AI nhỏ gọn nằm ở thanh điều khiển bên phải cho phép nhập lệnh đổi giao diện/style nhanh chóng bằng văn bản.
Giai đoạn 5 Kết xuất Video Tất định (Deterministic Rendering)

Quy trình biến cấu trúc Web động thành tệp video vật lý (MP4/WebM). Quy trình kết xuất tất định đảm bảo chất lượng hình ảnh đồng đều đến từng pixel.

npm run render // (Hoặc npx hyperframes render)
1. Nhúng nội dungFont & CDN Scripts được nhúng cục bộ để tránh lỗi mạng.
2. Headless ChromeChạy một phiên bản ẩn trình duyệt Chrome để chạy trang web.
3. Chụp Khung HìnhDuyệt timeline chụp từng frame ảnh chất lượng cao.
4. FFmpeg StreamGhép luồng âm thanh cùng chuỗi frame ảnh xuất file video.
Giai đoạn 6 Triển khai quy mô lớn (Scaling & Deployment)

Khi bạn cần sản xuất hàng loạt hàng nghìn video cá nhân hóa chỉ trong chốc lát.

  • Multi-Worker: Tự động phân tách và xử lý song song các luồng frame dựa trên tổng số nhân CPU phần cứng hiện có.
  • AWS Lambda: Đưa quá trình render lên môi trường serverless đám mây, giúp rút ngắn thời gian render video dài từ vài tiếng xuống vài giây.
